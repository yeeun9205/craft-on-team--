# 표접 (標蝶)
> *"낭떠러지에서 떨어지지 않으려면 영원히 달려야만 하는 걸까? 아니면 내가 믿어 온 낭떠러지의 정체를, 마주해야 하는 걸까?"*

## 시놉시스
여름방학을 앞둔 평범한 고등학교의 하루.  
늘 책상에 엎드려 잠만 자는 **서윤**과, 한순간도 멈추지 않고 달리는 전교권 모범생 **하린**은 오랜 단짝이다.  
모처럼 여유를 부리며 평온한 낮과 노을 지는 운동장의 낭만을 함께 나눈 두 사람.  
하지만 야간자율학습이 시작된 어두운 밤, 잠깐의 엇갈림 속에서 서윤은 하린이 숨겨온 위기와 마주하게 되는데—  
**과연 서윤은 소중한 친구를 지켜낼 수 있을까?**

## 안내
- 서윤이(혜리)와 하린이(승아)의 이야기는 이후에 계속됩니다.
- 현재 플레이 가능한 콘텐츠는 게임의 일부만 구현한 버전입니다.
- 이후 이야기는 추후 업데이트를 통해 공개될 예정입니다.
- 플레이해 주셔서 감사합니다.
- *(※ 본 게임에는 일부 플레이어에게 불쾌감이나 심리적 불편함을 유발할 수 있는 연출 및 민감한 소재가 포함되어 있으니 플레이에 유의해 주시기 바랍니다.)*

## 다운로드
[게임 다운로드 (v1.0)](https://github.com/yeeun9205/craft-on-team--/releases/tag/v1.0)

## 실행 방법
1. 위 다운로드 링크에서 `pubg_project-1.0-pc.zip` 파일을 다운로드합니다.
2. 다운로드한 zip 파일의 압축을 모두 해제합니다.
3. 압축 해제된 폴더 안의 `pubg_project.exe`를 더블클릭하여 실행합니다.
