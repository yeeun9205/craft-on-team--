# 표접 (標蝶)
> 반복되는 하루 끝, 소중한 친구를 구하기 위해 시간을 거슬러 오르는 미스터리 비주얼 노벨

> **안내**  
> 서윤이(혜리)와 하린이(승아)의 이야기는 이후에 계속됩니다.  
> 현재 플레이 가능한 콘텐츠는 게임의 일부만 구현한 버전입니다.  
> 이후 이야기는 추후 업데이트를 통해 공개될 예정입니다.  
> 플레이해 주셔서 감사합니다.

## 다운로드
[게임 다운로드 (v1.0)](https://github.com/yeeun9205/craft-on-team--/releases/tag/v1.0)

## 실행 방법
1. 위 다운로드 링크에서 `pubg_project-1.0-pc.zip` 파일을 다운로드합니다.
2. 다운로드한 zip 파일의 압축을 모두 해제합니다.
3. 압축 해제된 폴더 안의 `pubg_project.exe`를 더블클릭하여 실행합니다.

## 게임 소개
- **장르**: 학원 미스터리 / 타임루프 비주얼 노벨 (Ren'Py)
- **특징 및 재미 포인트**:
  - 평범한 학교생활 속에 숨겨진 친구의 위기와 복선을 찾아가는 몰입감 있는 스토리
  - 교실, 강당, 급식실 등 공간을 직접 탐색하는 포인트 앤 클릭 조사 파트
  - 선택지와 연출에 따라 변화하는 긴장감 넘치는 전개
